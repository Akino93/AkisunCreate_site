# AkisunCreate Release Checklist

公開前に人間が判断すべき項目と、技術的な確認事項を分離したチェックリスト。

## 1. Human Approval — 必須

- [ ] **最終ビジュアル承認**
  - ロック／ストリートの勢いがAkisunCreateらしいか
  - 太陽マスコットの見せ方がブランドとして採用可能か
  - 企業サイトとして読みやすさ・信頼感を損なっていないか
- [ ] **掲載実績の最終確認**
  - 「15+プロダクト」「3 yrs」表記をそのまま公開してよいか
  - 社員食堂アンケート／デザインシステム／AI導入支援の記載に守秘義務上の問題がないか
- [ ] **個人情報・プロフィール方針**
  - 現状は個人名・顔写真を出さない構成でよいか
  - 公開メールアドレス `thedashing.akky@gmail.com` をそのまま使うか
- [ ] **公開先を決定**
  - 推奨：Vercel または GitHub Pages
  - 独自ドメインを接続するか決定

## 2. Completed — 実装済み

- [x] 1ページ構成の情報設計
- [x] UI/UX × 業務設計 × AI活用のポジショニング
- [x] ポートフォリオ実績の抜粋
- [x] PC / モバイルのレスポンシブ対応
- [x] モバイルナビゲーション
- [x] キーボードフォーカス表示
- [x] スキップリンク
- [x] `prefers-reduced-motion` 対応
- [x] favicon
- [x] OGP基本メタ情報
- [x] 問い合わせメール導線

## 3. Before Publish — 技術確認

- [ ] 実機でスマホ表示を確認
- [ ] Chrome / Safari で表示確認
- [ ] メールリンクが期待どおり開くことを確認
- [ ] すべてのナビゲーションリンクが正しい位置へ遷移することを確認
- [ ] Lighthouseで Accessibility / Best Practices / SEO を確認
- [ ] 本番URL確定後に `og:url` を追加
- [ ] OGP用1200×630px画像を用意し、`og:image` / `twitter:image` を追加
- [ ] 独自ドメイン利用時はcanonical URLを追加

## 4. Recommended Release Order

1. オーナーがサイトの見た目・掲載内容を確認
2. 必要なデザイン修正
3. 実績・メールアドレスの公開可否を確定
4. ホスティング先へデプロイ
5. 本番URLをHTMLのOGP/canonicalへ反映
6. Lighthouse・実機で最終確認
7. 独自ドメイン接続（必要な場合）
